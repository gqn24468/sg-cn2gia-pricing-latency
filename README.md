## 延迟什么水平：三网回程 CN2 GIA 是关键

SG_8 的卖点是回程：电信、联通、移动三个运营商回国都走 CN2 GIA 骨干（AS4809），路径是新加坡数据中心 → CTGNet 新加坡 → CTG 香港 → CN2 GIA 骨干 → 大陆落地。普通走 163 线路的新加坡 VPS，晚高峰丢包率能到 30% 以上；SG_8 的第三方监测数据里丢包基本可以忽略。

具体延迟数字（第三方多节点监测整理）：华南 55–75ms，华东 60–80ms，华北 70–95ms，西部 80–100ms。分运营商看，电信方向明显更好，广州约 46ms、上海 67ms、北京 74ms；联通方向 100ms 上下；移动波动较大，从约 70ms 到 125ms 都有记录。

国际带宽方面，SG_8 的国际端口给了 10Gbps，第三方 iperf3 实测到苏州约 5.6Gbps/77ms、宁波约 3.7Gbps/78ms、东京 15.1Gbps/68ms。国内方向的实际速率上限就是套餐标注的 1.5–5Gbps。
